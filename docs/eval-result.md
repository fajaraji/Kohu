- Conflict detection, the SAM marking rule and the crop padding were developed on this same corpus and clip. These are not held-out results; they show the pipeline works end to end on the demo data, nothing more.
- Video step times come from the committed reviewed steps, which are the model's output approved without edits. Ground truth is the narration start of each step from the recording run.
- Masks: every mark was drawn from the SAM box, not a decoded SAM mask, because `meta-sam-parser` could not be installed in the build sandbox. The Docker image installs it, which should switch drawing to masks; that path was not run here.
